# Проверка начального каркаса

Дата: 17 октября 2026. Проверки выполнены локально на Windows x64.
Инструменты: Visual Studio Build Tools 2022, MSVC 19.44.35228.0,
CMake 3.31.6, Windows SDK 10.0.26100.0.

| Команда / проверка | Итог |
| --- | --- |
| `build.bat` | Release собран, exit 0 |
| `build.bat -Configuration Debug` | Debug собран, exit 0 |
| Повторный `build.bat` | Ninja: no work to do; exit 0 |
| `mdamp.unit` | Pass в Release и Debug |
| `mdamp.window_smoke` | Pass в Release и Debug |
| Ninja dependency database | Заголовок представления учтён для приложения |

Unit-тест проверяет границы форматирования длительности, целочисленное
переполнение и безопасные размеры layout при малом/обычном/широком окне.
Smoke-тест проверяет создание и уничтожение собственного скрытого HWND,
имя окна, верхнее меню и отключённый транспорт. Всего два CTest-теста.

При подготовке исправлены совместная обработка manifest средствами CMake в
Debug-сборке и кодировка определения зависимостей русскоязычного MSVC/Ninja.
Последующие проверки выполнены после исправлений.

Не выполнены: визуальное сравнение, ручной обход GUI, playback, тесты устройств,
плагинов, чистой машины и установщика. Их успех не заявляется. В текущей версии
большинство этих функций отсутствует, а не просто «не проверено».
