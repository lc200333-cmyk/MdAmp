# Происхождение

MdAmp создаётся как самостоятельный проект по запросу владельца. Начальные
C++/CMake/PowerShell-файлы и оформление написаны для MdAmp, без копирования
оригинального кода или ресурсов Winamp.

Предыдущий локальный REA-разбор используется только как источник функциональных
наблюдений и перечень исследовательских пробелов. Raw evidence, декомпиляция,
исходники скина и пакеты плагинов здесь не хранятся и не публикуются.

Наличие описаний не означает, что динамическая логика всех плагинов восстановлена,
что MdAmp совместим с Winamp API или что визуальное совпадение было проверено.
В документации и интерфейсе состояние каркаса обозначается явно.
