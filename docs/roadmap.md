# Оставшийся объём

Первая версия играет аудио и имеет собственные Modern-подобные основные окна.
Пользовательский запрос на полное повторение всех скинов/плагинов ещё не закрыт.
Не следует переименовывать этот статус в «полный клон».

1. Живое визуальное сравнение с Modern: все размеры/DPI, typography, состояния
   кнопок, раскладка меню/playlist/EQ. Устранить timeout desktop capture.
2. Дополнить настройки по матрице `ui-parity.md`, добавить notifier, artwork,
   ticker, playlist shade, persistent library, metadata и ReplayGain.
3. Проверить форматы на больших/повреждённых файлах, аудиоустройства/переключения,
   latency, клиппинг, качество EQ и parameter smoothing; затем crossfade/gapless.
4. Вводить дополнительные codecs/encoders и расширения отдельно, с проверкой
   происхождения/лицензий и реальными fixtures. Отдельно решать legacy DLL ABI.
5. AVS/MilkDrop, видео, CD, устройства и online-сервисы — самостоятельные крупные
   подсистемы, а не набор картинок диалогов. Для каждого модуля нужен рабочий
   алгоритм/протокол и acceptance tests из `plugin-coverage.md`.
6. Проверка portable-пакета на чистой Windows, installer/signing и лицензия
   собственного кода — отдельные решения владельца, не текущий автопуш.

Открытые вопросы динамического MAKI и runtime-ветвей из исходного REA-разбора
сохраняются; наличие resource template не доказывает реализованное поведение.
