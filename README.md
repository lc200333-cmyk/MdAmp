# MdAmp

Самостоятельный проект настольного аудиоплеера для Windows на C++17 / Win32.
Текущее состояние: **0.1.0-dev, стартовый каркас, не готовый аудиоплеер**.

## Что уже есть

- Окно MdAmp с собственным простым оформлением, изменением размера и меню.
- Рабочие команды File → Exit и Help → About MdAmp.
- Заготовки области плейлиста и транспорта. Кнопки воспроизведения и ещё не
  реализованные пункты меню намеренно отключены.
- Локальная x64-сборка, модульные проверки и smoke-тест создания скрытого окна.

Здесь пока нет воспроизведения, эквалайзера, медиатеки, сохранения настроек,
совместимости с DLL-плагинами или полного интерфейса Modern.

## Сборка без GitHub

Установите Visual Studio Community либо Visual Studio Build Tools с компонентами:

- «Разработка классических приложений на C++»;
- MSVC для x64/x86;
- Windows SDK;
- средства C++ CMake для Windows (включая Ninja).

Из PowerShell в корне проекта:

```powershell
.\build.bat
# Отладочная конфигурация:
.\build.bat -Configuration Debug
```

Скрипт находит полную установленную цепочку инструментов через `vswhere`,
собирает приложение и запускает CTest. При ошибке сборки или теста возвращает
ненулевой код. Запускать PowerShell от администратора не требуется.

Результат Release: `build/Release/bin/MdAmp.exe`.

```powershell
.\build\Release\bin\MdAmp.exe
```

Можно также открыть `CMakeLists.txt` в Visual Studio. Git нужен только для
управления исходниками, а не для компиляции. Сборка не загружает зависимости.

## Границы проекта

Ранее выполненный локальный разбор Winamp используется как источник наблюдений
о функциях, а не как поставляемый код. Бинарники, исходники скина, декомпиляция,
графика, шрифты и плагины Winamp в репозиторий не включены. Это не официальный
Winamp и не его переименованная сборка. Совместимость с его плагинами не заявлена.

Лицензия распространения собственного проекта пока не выбрана владельцем;
файл с открытой лицензией автоматически не добавлялся.
